## ✨ คุณสมบัติเด่นของระบบ (Features)

1. **Dashboard แผนการเรียน 4 ปี (8 ภาคการศึกษา):**
   - แสดงแผนการเรียนแยกตามชั้นปี (ปี 1 - 4) และภาคการศึกษา (เทอม 1 และ เทอม 2)
   - แต่ละปีและภาคการศึกษาสามารถ **ย่อ/ขยาย (Accordion / Collapse)** ได้อย่างอิสระ พร้อมปุ่ม "ขยายทั้งหมด / ย่อทั้งหมด"
   - แสดงรหัสวิชา, ชื่อวิชา, หน่วยกิต, Section, วันเวลาเรียน, อาจารย์ผู้สอน และเกรดที่คาดหมาย
   - มี Empty State ที่สวยงามเมื่อยังไม่มีวิชาในภาคนั้นๆ

2. **ระบบค้นหาและเพิ่มรายวิชา (Course Selection Modal):**
   - ค้นหารายวิชาด้วยรหัสวิชา (เช่น `204111`), ชื่อวิชา
   - กรองตามหมวดหมู่วิชาได้: *วิชาศึกษาทั่วไป, วิชาแกน, วิชาเอกบังคับ, วิชาเอกเลือก, และวิชาเลือกเสรี*
   - **ระบบป้องกันการลงซ้ำ:** แจ้งเตือนและป้องกันไม่ให้เพิ่มวิชาเดิมซ้ำในภาคการศึกษาเดียวกัน
   - **รองรับการเรียนซ้ำ (Retake):** สามารถเพิ่มวิชาเดียวกันในต่างภาคการศึกษาได้

3. **ระบบคำนวณเกรดเฉลี่ยแบบ Real-time (Dynamic GPA Calculator):**
   - คำนวณ GPA แยกตามแต่ละภาคการศึกษา
   - คำนวณ GPA แยกตามแต่ละชั้นปี
   - คำนวณ GPAX สะสมตลอด 4 ปี พร้อมประเมินเกณฑ์ผลการเรียน
   - คำนวณจำนวนหน่วยกิตรวมและเปอร์เซ็นต์ความคืบหน้าของหลักสูตร (เป้าหมาย 130 หน่วยกิต)
   - **ไม่นำวิชาที่ยังไม่ประเมินเกรดมาคำนวณ**
   - แสดงข้อความ *"ยังไม่มีข้อมูลเกรด"* แทนค่า `NaN` หรือ `Infinity` หากยังไม่มีการประเมิน
   - การเปลี่ยนแปลงเกรดหรือการเพิ่ม/ลบวิชาจะมีผลต่อเกรดเฉลี่ยทันที

4. **การออกแบบ UI/UX ทันสมัย (Student Productivity Dashboard):**
   - ธีมสีประจำมหาวิทยาลัยเชียงใหม่ (CMU Purple & Modern Violet `#682c91`)
   - รองรับ Responsive เต็มรูปแบบ ใช้งานได้สะดวกบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน
   - ใช้ฟอนต์ภาษาไทย **Prompt** จาก Google Fonts อ่านง่าย สบายตา
   - มีระบบ Toast Notifications แจ้งผลการทำงานชัดเจน
   - รองรับการพิมพ์หรือ Export เป็น PDF ผ่านปุ่มพิมพ์

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Backend:** PHP 8.0+ (PDO, Prepared Statements, Session Auth, JSON RESTful API)
- **Database:** MySQL 5.7+ / MariaDB (InnoDB, Foreign Keys, utf8mb4)
- **Frontend:** Vanilla HTML5, CSS3, JavaScript (Fetch API, Async/Await)
- **CSS Framework:** Bootstrap 5.3 + Bootstrap Icons
- **Typography:** Prompt (Google Fonts)

## 💻 เกณฑ์การคิดแต้มระดับคะแนน (Grading Scale)

| เกรด | แต้มคะแนน (Grade Point) |
|:---:|:---:|
| **A** | 4.00 |
| **B+** | 3.50 |
| **B** | 3.00 |
| **C+** | 2.50 |
| **C** | 2.00 |
| **D+** | 1.50 |
| **D** | 1.00 |
| **F** | 0.00 |
| **ยังไม่ประเมิน (-)** | ไม่นำมาคำนวณ |

**สูตรการคำนวณ:**
$$\text{GPA} = \frac{\sum (\text{หน่วยกิต} \times \text{แต้มคะแนน})}{\sum (\text{หน่วยกิตของวิชาที่มีการประเมินเกรด})}$$
